## 七、🚨 故障处理

**A. 突然连不上了?** 按顺序排查:
1. 换个本地网络试(切手机热点),排除自己网络问题。
2. 电脑 PowerShell 测端口:`Test-NetConnection 46.137.211.222 -Port 443`
   - `True` → 服务器通,是客户端问题(检查订阅是否刷新、节点是否选中、Tun/系统代理是否开)。
   - `False` → 进 B。
3. SSH 上服务器:`systemctl restart sing-box`,再测。

**B. IP 被墙了(443 和 22 都 False)?**
说明这个静态 IP 被封了。重新抽一个:
1. Lightsail → Networking → 删掉旧静态 IP → Create 新的 → 绑到实例。
2. PowerShell 测新 IP 的 22 端口,`True` 才用。
3. 把新 IP 更新到 Gist 的 `server:` 行 → 刷新订阅。
4. 同步服务器记录:`sudo sed -i 's/^SERVER_IP=.*/SERVER_IP=新IP/' /etc/sing-box/meta.env`

**C. 抽几次 IP 都被墙?**
AWS 新加坡 IP 段对国内不友好。考虑:
- 换 **AWS 东京区域**(重建实例,线路通常更好)。
- 或换 **CN2 GIA 线路**的服务商(花钱但稳)。

## 八、🔑 安全

- 节点钥匙(UUID / vless 链接)等于密码,**别公开发、别截图传**。
- 给朋友用 → 用 `add-user.sh` **每人开独立 UUID**,不要共用。
- Gist 务必设 **Secret(私密)**。
- 定期(或怀疑泄露时)用 `add-user.sh` 换新 UUID、删旧的。
